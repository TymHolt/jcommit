# JCommit
A git front-end and helper written in Java. To run this application, you need to have git installed
and available from the command line.

![Screenshot](/img/screenshot.png?raw=true "Screenshot")

### Installation
Head over to the [releases](https://github.com/TymHolt/jcommit/releases) section of this
repository. There you will find an executable .jar file as well as a .deb package to install on 
Debian based systems.

### Build
To build this application yourself, you will need
[smplmake v0.0.1](https://github.com/TymHolt/smpl-make/releases). Run

> smplmake

to get an executable .jar file.
